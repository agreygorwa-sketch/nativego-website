Administrator

The administrator runs the site. Only an admin account can open the admin pages. The admin keeps the marketplace safe: checking providers, managing accounts, handling reports, and watching the numbers.

Verification queue

Providers waiting to be checked sit in the verification queue. The administrator opens each one, looks at the identity documents and certificates, and approves or rejects them, with a reason. Approved providers become visible to tourists; rejected ones get a reason and stay hidden. This is the trust gate, and it is the first thing on the dashboard.

See the queue on the live system: Verification queue.

Reported cases

Reports from tourists arrive as cases. The administrator reads each report, looks at the messages and the request behind it, and decides: warn the provider, suspend the account, or close the case with no action. Both sides are told the outcome.

See the cases on the live system: Reported cases.

System statistics

The dashboard counts the whole marketplace: how many accounts, how many requests, how many reviews, and what has happened recently. The numbers come from the database, so they are always up to date.

See the numbers on the live system: Statistics dashboard.

What the administrator does

Administrator requirements and where they happen
Task What the admin does Requirement What happens
Log in Log in with admin credentials. The system checks the role is admin before opening the dashboard. FR-15 Admin dashboard opens.
Approve verifications Look at a provider's documents and approve or reject them, with a reason. FR-16 Approved providers become visible to tourists; rejected ones get a reason.
Manage accounts Suspend or activate any account. FR-17 The account flag changes; a suspended account cannot log in.
Handle reports Read reported cases, look at the messages and the request, and decide: warn, suspend, or close the case. FR-18 Case closed; both sides are told.
View statistics See the totals: accounts, requests, reviews, and recent activity. FR-19 A statistics dashboard with the counts.

Open the admin dashboard

The admin pages live on the live system, not on this static site, because they change the database and need an admin login. Open the admin dashboard on the live system. The demo admin account is admin@nativego.co.ke. The admin area also keeps an activity log — a diary of who did what — so every decision is recorded.

Admin only

If a tourist or provider tries to open an admin page, they are refused. Role checks run on every admin page, not just at login.
